Service Daemon is a Python + Postgre\+SQL data layer and demo app for managing apartment service workflows (users, units, tenants, service types, bookings, and provider assignments). It ships with a database schema, helpers for initialization/\+connection pooling, and an example script to show common reads/\+writes.

If you are new, follow the {\bfseries{Novice Setup}} below. If you are experienced and want more control, skip to {\bfseries{Senior Setup}}.
