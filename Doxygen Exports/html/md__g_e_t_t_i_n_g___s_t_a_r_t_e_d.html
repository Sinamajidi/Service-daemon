Getting Started - Complete Setup Guide

This guide walks you through setting up the entire project from scratch.

Prerequisites

  • Git (for cloning/pulling the repository)
  • Python 3.7+ (python --version)
  • PostgreSQL OR Docker

Setup Steps

Step 1: Get the Code

# If starting fresh
git clone <your-repo-url>
cd Service-daemon
# If already cloned
cd Service-daemon
git pull

Step 2: Set Up Python Environment (Recommended)

# Create virtual environment
python -m venv venv
# Activate it
# On WSL/Linux/macOS:
source venv/bin/activate
# On Windows:
venv\Scripts\activate
# You should see (venv) in your prompt

Step 3: Install Python Dependencies

pip install -r requirements.txt

Step 4: Set Up PostgreSQL

Option A: Automated Setup (WSL/Linux)

./setup_postgresql.sh

This will:

  • Install PostgreSQL if needed
  • Start the service
  • Create the database
  • Set up your .env file

Option B: Manual Setup See POSTGRESQL_SETUP_GUIDE.md for detailed instructions for:

  • WSL/Linux
  • macOS
  • Windows
  • Docker

Step 5: Verify Setup

# Run diagnostic test
python diagnostic_test.py
# Run full test
python test_setup.py

Both should complete successfully.

Step 6: Initialize Database

# This creates all tables and schema
python database/db_init.py

You should see:

Initializing database...
Database initialized successfully!

Step 7: Run Example

python examples/example_usage.py

You should see the example creating sample data and running queries.

Quick Troubleshooting

Import errors?

# Make sure you're in project root
pwd
# Verify structure
python test_setup.py

Database connection errors?

# Check PostgreSQL is running
# WSL/Linux:
sudo service postgresql status
# macOS:
brew services list
# Check your .env file
cat .env

"Module not found" errors?

# Make sure dependencies are installed
pip install -r requirements.txt
# Check you're in the virtual environment
which python
# Should show path with 'venv' in it

Daily Workflow

Starting Work

# 1. Pull latest changes
git pull
# 2. Activate virtual environment
source venv/bin/activate # or venv\Scripts\activate on Windows

Testing Your Changes

# Full test

Committing Changes

git add .

Common Commands

Database Management

# Connect to database
psql -h localhost -U postgres -d apartment_mgmt
# Reinitialize database (DROPS ALL DATA!)
python database/db_init.py
# In psql shell:
\l # List databases
\dt # List tables
\d+ users # Describe users table
\q # Quit

Python

# Install new package
pip install package-name
pip freeze > requirements.txt # Update requirements
# Run Python REPL with imports
python
>>> from database import get_user_access
>>> users = get_user_access()
>>> users.get_all_user_ids()

For Team Members

If you're a collaborator joining the project:

  1. Clone the repository
    git clone <repo-url>
    cd Service-daemon
  2. Follow Steps 2-7 above
  3. Your own .env file
    cp .env.example .env
    nano .env # Edit with YOUR credentials
    Never commit your .env file!
  4. Stay synced
    git pull # Before starting work
    git push # After committing changes

See TEAM_SETUP.md for more details.
